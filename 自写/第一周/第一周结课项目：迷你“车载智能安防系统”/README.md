项目需求：
状态 A（设防模式）：数码管前两位显示 S1（Security 1）。
LED 呼吸灯缓慢闪烁（模拟安防指示灯）。
如果按下 K1 键，立即进入状态 B。
状态 B（警报模式）：数码管前两位显示 AL（Alarm）。
蜂鸣器发出急促的“滴-滴-滴”声（频率随时间变快）。
LED 全速闪烁。
数码管后三位开始倒计时（从 60 秒倒计到 0）。
状态 C（解除模式）：长按 K1 键（或连按两下）恢复状态 A。
2. 核心技术指标：
代码结构：必须全部基于 Timer0 或 Timer1 的标志位（Flag），while(1) 里不允许出现任何 delay() 函数。
数码管消隐：显示必须清晰，不能有鬼影。
变量管理：尝试使用 unsigned char 节省内存，使用 static 保证变量的私有记忆。
